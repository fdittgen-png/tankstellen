1. Überblick

Sparkilo ist eine kostenlose, quelloffene App zum Vergleich von Kraftstoff- und Ladepreisen mit optionaler Fahrtenaufzeichnung. Sie ist local-first aufgebaut: Alles, was die App über Sie weiß, bleibt auf Ihrem Telefon, sofern Sie nicht eine Funktion einschalten, die ausdrücklich etwas anderes erklärt. Es gibt keine Werbung, keine Tracking-Pixel, keine Werbe-IDs und kein Analyse-SDK. Diese Erklärung ist so verfasst, dass sie die EU-Datenschutz-Grundverordnung (DSGVO, engl. GDPR) erfüllt; sie gilt für alle Nutzerinnen und Nutzer, unabhängig davon, wo Sie sich befinden.

Die App ist quelloffen — jede Aussage unten lässt sich im Code überprüfen. Eine maschinenlesbare Zusammenfassung der verarbeiteten Daten wird in docs/privacy/data_inventory.json geführt, und die eigenen Tests der App schlagen fehl, wenn diese Seite, die Store-Angaben und der Code auseinanderlaufen.

Je nachdem, wie Sie TankSync nutzen, ändert sich der Verantwortliche für Ihre synchronisierten Daten:

  • Kein TankSync (Standard): Auf keinem von uns betriebenen Server wird etwas gespeichert. Ihre Daten bleiben auf Ihrem Gerät und Sie haben die alleinige Kontrolle darüber.
  • Private Datenbank: Sie verbinden Ihr eigenes Supabase-Projekt. Sie sind der Verantwortliche; wir sehen diese Daten nie.
  • Einer Gruppe beitreten: Sie verbinden ein Supabase-Projekt, das von einer Ihnen bekannten Person (Familie, Freunde) betrieben wird. Diese Person ist der Verantwortliche für die gemeinsame Datenbank.
  • Sparkilo Community: Sie verbinden die gemeinsame Datenbank, die vom oben genannten Entwickler betrieben wird (Supabase, gehostet in der EU — AWS eu-central-1, Frankfurt). Der Entwickler ist der Verantwortliche; Supabase, Inc. ist Auftragsverarbeiter und an seine Auftragsverarbeitungsbedingungen gebunden.

Die App teilt Ihnen vor dem Verbinden mit, welcher dieser Fälle zutrifft, und zeigt es erneut unter Einstellungen → Datenschutz-Dashboard an.

6. Datensicherheit

  • Sämtliche Netzwerkkommunikation verwendet HTTPS (TLS bei der Übertragung); die App verweigert unverschlüsselte HTTP-Sync-Endpunkte.
  • API-Schlüssel, Ihr GitHub-Token und die TankSync-Sitzung liegen in plattformeigener verschlüsselter Speicherung (Android Keystore / iOS Keychain).
  • Lokale Datenbanken sind AES-verschlüsselt mit einem Schlüssel, der im Keystore / Keychain aufbewahrt wird — einschließlich aufgezeichneter Fahrten, Fahrzeugdaten, Wartungserinnerungen und zwischengespeicherter Preise.
  • Auf dem Server ist jede Tabelle durch Row-Level-Security geschützt, sodass ein Konto immer nur seine eigenen Zeilen lesen oder löschen kann; geteilte Bewertungen und Community-Preismeldungen sind die einzigen Zeilen, die für andere angemeldete Nutzer sichtbar sind.
  • Fehlerprotokolle werden vor dem Speichern oder Senden um E-Mail-Adressen, Koordinaten und Tokens bereinigt.
  • Es werden keine Daten an einen Server gesendet, es sei denn, Sie führen eine Suche aus, öffnen eine Karte oder aktivieren TankSync / Diagnose.

Für jedes Recht gibt es eine Schaltfläche in der App:

  • Auskunft — Einstellungen → Datenschutz-Dashboard zeigt jede auf dem Gerät gespeicherte Kategorie und, wenn verbunden, jede Zeile in Ihrer TankSync-Datenbank.
  • Export (Übertragbarkeit) — Datenschutz-Dashboard → Alle meine Daten exportieren erzeugt eine ZIP-Datei mit einer maschinenlesbaren JSON-Datei pro Kategorie (Favoriten, Alarme, Profile, Routen, Preisverlauf, Fahrzeuge, Tankvorgänge, Fahrten mit GPS-Messpunkten und einer GPX-Datei pro Fahrt, Referenzwerte, Wartungserinnerungen, Ladeprotokolle, Ihr Einwilligungsprotokoll) sowie einem JSON-Export jeder Servertabelle.
  • Berichtigung — bearbeiten Sie jeden Eintrag direkt in der App; die Änderung wird synchronisiert, wenn TankSync eingeschaltet ist.
  • Löschung — siehe Abschnitt 8.
  • Einschränkung / Widerspruch — schalten Sie TankSync, die Fahrten-Synchronisierung, den Kachel-Proxy oder die Diagnose in den Einstellungen aus; widerrufen Sie die Standort-, Bluetooth-, Kamera- oder Benachrichtigungsberechtigung in den Einstellungen Ihres Geräts.
  • Einwilligung widerrufen — Einstellungen → Datenschutz & Daten listet jede Einwilligung mit dem Datum, an dem Sie sie erteilt haben, und der Version der Erklärung, die Sie gesehen haben; jede lässt sich abschalten, und die App beendet die entsprechende Verarbeitung sofort.

8. Löschen Ihres Kontos und Ihrer Daten

Sie können alles selbst löschen, direkt in der App — ohne Supportanfrage:

  • Lokale Daten: Einstellungen → Datenschutz-Dashboard → Alle Daten löschen entfernt jede Datenbank, die die App auf dem Gerät führt — Profile, Favoriten, Alarme, Preisverlauf, zwischengespeicherte Preise, Fahrzeuge, Tankvorgänge, aufgezeichnete Fahrten und ihre GPS-Messpunkte, OBD2-Referenzwerte und Adapter-Caches, Wartungserinnerungen, Erfolge, Fehlerprotokolle, API-Schlüssel, Tokens und die Daten des Startbildschirm-Widgets — und versetzt die App in den Zustand des ersten Starts zurück.
  • TankSync-Konto und Serverdaten: TankSync → Datentransparenz → Konto löschen löscht in einer einzigen Transaktion jede Zeile, die Ihnen gehört (Favoriten, Alarme, ignorierte Tankstellen, Preismeldungen, Inhaltsmeldungen, Fahrzeuge, Tankvorgänge, Routen, Referenzwerte, Bewertungen, Fahrten, von Ihnen erteilte oder erhaltene Fahrtenfreigaben, Wartezeit-Meldungen, Sync-Einstellungen, Löschprotokolle und Ihre Nutzerzeile) und löscht anschließend die Kontoidentität selbst, einschließlich einer etwaig verknüpften E-Mail-Adresse. Konnte eine Tabelle nicht gelöscht werden, teilt Ihnen die App mit, welche, statt einen Erfolg vorzutäuschen. Dies kann nicht rückgängig gemacht werden.
  • Einzelne Einträge: jeder Favorit, Alarm, jedes Fahrzeug, jeder Tankvorgang, jede Fahrt, Preismeldung und Inhaltsmeldung kann einzeln gelöscht werden; Löschungen werden an Ihre anderen Geräte weitergegeben.

Wenn Sie nicht mehr auf die App zugreifen können, können Sie die Löschung beantragen, indem Sie den Entwickler kontaktieren (Abschnitt 11); bitte schreiben Sie von der mit Ihrem Konto verknüpften E-Mail-Adresse, damit wir die Inhaberschaft prüfen können. Ein anonymes Konto, das nie mit einer E-Mail-Adresse verknüpft wurde, kann von niemandem — auch nicht von uns — ohne das Gerät identifiziert werden, auf dem es erstellt wurde.
