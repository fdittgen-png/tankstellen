1. Présentation

Sparkilo est une application gratuite et open source de comparaison des prix des carburants et de la recharge des véhicules électriques, avec enregistrement optionnel des trajets. Elle est conçue selon le principe local-first : tout ce que l'application sait de vous reste sur votre téléphone, sauf si vous activez une fonctionnalité qui indique le contraire. Il n'y a ni publicité, ni pixels de suivi, ni identifiants publicitaires, ni SDK d'analyse d'audience. La présente politique est rédigée pour satisfaire au Règlement général sur la protection des données de l'UE (RGPD / GDPR) ; elle s'applique à tous les utilisateurs, où que vous soyez.

L'application est open source — chaque affirmation ci-dessous peut être vérifiée dans le code. Un résumé lisible par machine des traitements effectués est tenu à jour dans docs/privacy/data_inventory.json, et les tests de l'application échouent si cette page, les déclarations des boutiques d'applications et le code divergent.

Selon la manière dont vous utilisez TankSync, le responsable du traitement de vos données synchronisées change :

  • Sans TankSync (par défaut) : rien n'est stocké sur un serveur que nous exploitons. Vos données restent sur votre appareil et vous en avez le contrôle exclusif.
  • Base de données privée : vous connectez votre propre projet Supabase. Vous êtes le responsable du traitement ; nous ne voyons jamais ces données.
  • Rejoindre un groupe : vous connectez un projet Supabase exploité par une personne que vous connaissez (famille, amis). Cette personne est le responsable du traitement de la base de données partagée.
  • Sparkilo Community : vous connectez la base de données partagée exploitée par le développeur nommé ci-dessus (Supabase, hébergé dans l'UE — AWS eu-central-1, Francfort). Le développeur est le responsable du traitement ; Supabase, Inc. est un sous-traitant lié par ses conditions de traitement des données.

L'application vous indique lequel de ces cas s'applique avant la connexion, et l'affiche à nouveau dans Paramètres → Tableau de bord confidentialité.

4. Données que nous ne collectons PAS

  • Nom ou numéro de téléphone (une adresse e-mail n'est stockée que si vous en associez une à votre compte TankSync optionnel)
  • Données de paiement ou bancaires
  • Données de santé ou de forme physique
  • Contacts, messages ou journaux d'appels
  • Photos, vidéos ou fichiers, au-delà de la photo de ticket que vous choisissez de scanner
  • Historique de navigation
  • Identifiants publicitaires

Les logos des enseignes sont fournis avec l'application. Leur chargement depuis Internet (logo.clearbit.com, qui recevrait votre adresse IP) est désactivé sauf si vous l'activez dans Paramètres → Confidentialité.

6. Sécurité des données

  • Toutes les communications réseau utilisent HTTPS (TLS en transit) ; l'application refuse les points de terminaison de synchronisation en HTTP non chiffré.
  • Les clés API, votre jeton GitHub et la session TankSync sont conservés dans le stockage chiffré natif de la plateforme (Android Keystore / iOS Keychain).
  • Les bases de données locales sont chiffrées en AES avec une clé conservée dans le Keystore / Keychain — y compris les trajets enregistrés, les données de véhicule, les rappels d'entretien et les prix en cache.
  • Sur le serveur, chaque table est protégée par une sécurité au niveau des lignes (row-level security), de sorte qu'un compte ne peut jamais lire ou supprimer que ses propres lignes ; les évaluations partagées et les signalements de prix communautaires sont les seules lignes visibles par les autres utilisateurs connectés.
  • Les traces d'erreur sont expurgées des adresses e-mail, coordonnées et jetons avant d'être stockées ou envoyées.
  • Aucune donnée n'est envoyée à un serveur, sauf si vous lancez une recherche, ouvrez une carte ou activez TankSync / les diagnostics.

7. Vos droits

En vertu des articles 15 à 22 du RGPD, vous disposez du droit d'accès, de rectification, d'effacement, de limitation et de portabilité de vos données, du droit de vous opposer au traitement fondé sur l'intérêt légitime, et du droit de retirer votre consentement à tout moment sans que cela n'affecte la licéité du traitement antérieur. Chaque droit dispose d'un bouton dans l'application :

  • Accès — Paramètres → Tableau de bord confidentialité affiche chaque catégorie stockée sur l'appareil et, lorsque vous êtes connecté, chaque ligne de votre base de données TankSync.
  • Export (portabilité) — Tableau de bord confidentialité → Exporter toutes mes données génère un fichier ZIP contenant un JSON lisible par machine par catégorie (favoris, alertes, profils, itinéraires, historique des prix, véhicules, pleins, trajets avec échantillons GPS et un GPX par trajet, références, rappels d'entretien, journaux de recharge, votre registre de consentements) ainsi qu'un export JSON de chaque table serveur.
  • Rectification — modifiez n'importe quelle entrée directement dans l'application ; la modification est synchronisée si TankSync est activé.
  • Effacement — voir la section 8.
  • Limitation / opposition — désactivez TankSync, la synchronisation des trajets, le proxy de tuiles ou les diagnostics dans les Paramètres ; révoquez l'autorisation de localisation, Bluetooth, appareil photo ou notifications dans les réglages de votre appareil.
  • Retrait du consentement — Paramètres → Confidentialité et données liste chaque consentement avec la date à laquelle vous l'avez donné et la version de la politique que vous avez consultée ; chacun peut être désactivé, et l'application arrête immédiatement le traitement correspondant.
  • Réclamation — vous pouvez introduire une réclamation auprès d'une autorité de contrôle, en particulier dans l'État membre de l'UE de votre résidence habituelle, de votre lieu de travail ou du lieu de la violation alléguée. Nous apprécierions d'avoir d'abord la possibilité de répondre à votre préoccupation : fdittgen@gmail.com.

8. Suppression de votre compte et de vos données

Vous pouvez tout supprimer vous-même, directement dans l'application — aucune demande d'assistance n'est nécessaire :

  • Données locales : Paramètres → Tableau de bord confidentialité → Supprimer toutes les données efface chaque base de données que l'application conserve sur l'appareil — profils, favoris, alertes, historique des prix, prix en cache, véhicules, pleins, trajets enregistrés et leurs échantillons GPS, références OBD2 et caches d'adaptateur, rappels d'entretien, succès, traces d'erreur, clés API, jetons et données du widget de l'écran d'accueil — et remet l'application dans son état de premier lancement.
  • Compte TankSync et données serveur : TankSync → Transparence des données → Supprimer le compte efface en une seule transaction chaque ligne qui vous appartient (favoris, alertes, stations ignorées, signalements de prix, signalements de contenu, véhicules, pleins, itinéraires, références, évaluations, trajets, partages de trajets donnés ou reçus, signalements de temps d'attente, paramètres de synchronisation, enregistrements de suppression et votre ligne utilisateur), puis supprime l'identité du compte elle-même, y compris toute adresse e-mail associée. Si une table n'a pas pu être effacée, l'application vous indique laquelle, au lieu de prétendre que l'opération a réussi. Cette opération est irréversible.
  • Éléments individuels : chaque favori, alerte, véhicule, plein, trajet, signalement de prix et signalement de contenu peut être supprimé individuellement ; les suppressions se propagent à vos autres appareils.

Si vous n'avez plus accès à l'application, vous pouvez demander la suppression en contactant le développeur (section 11) ; veuillez écrire depuis l'adresse e-mail associée à votre compte afin que nous puissions en vérifier la propriété. Un compte anonyme qui n'a jamais été associé à une adresse e-mail ne peut être identifié par personne — nous compris — sans l'appareil sur lequel il a été créé.

9. Protection des mineurs

L'application ne s'adresse pas aux enfants de moins de 16 ans. Nous ne collectons pas sciemment de données personnelles auprès d'enfants ; si vous pensez qu'un enfant a créé un compte TankSync, contactez-nous et nous le supprimerons.
