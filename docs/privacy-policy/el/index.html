1. Επισκόπηση

Το Sparkilo είναι μια δωρεάν εφαρμογή ανοικτού κώδικα για τη σύγκριση τιμών καυσίμων και φόρτισης ηλεκτρικών οχημάτων, με προαιρετική καταγραφή διαδρομών. Είναι σχεδιασμένο με την αρχή local-first: ό,τι γνωρίζει η εφαρμογή για εσάς παραμένει στο τηλέφωνό σας, εκτός εάν ενεργοποιήσετε μια λειτουργία που δηλώνει ρητά το αντίθετο. Δεν υπάρχουν διαφημίσεις, pixel παρακολούθησης, διαφημιστικά αναγνωριστικά ούτε SDK αναλυτικών στοιχείων. Η παρούσα πολιτική έχει συνταχθεί ώστε να συμμορφώνεται με τον Γενικό Κανονισμό για την Προστασία Δεδομένων της ΕΕ (ΓΚΠΔ / GDPR)· ισχύει για κάθε χρήστη, όπου και αν βρίσκεστε.

Η εφαρμογή είναι ανοικτού κώδικα — κάθε δήλωση παρακάτω μπορεί να επαληθευτεί στον κώδικα. Μια μηχαναγνώσιμη σύνοψη των δεδομένων που υποβάλλονται σε επεξεργασία τηρείται στο docs/privacy/data_inventory.json, και οι ίδιες οι δοκιμές της εφαρμογής αποτυγχάνουν εάν αυτή η σελίδα, οι δηλώσεις στα καταστήματα εφαρμογών και ο κώδικας πάψουν να συμφωνούν.

  • Χωρίς TankSync (προεπιλογή): τίποτα δεν αποθηκεύεται σε κανέναν διακομιστή που λειτουργούμε εμείς. Τα δεδομένα σας παραμένουν στη συσκευή σας και μόνο εσείς τα ελέγχετε.
  • Ιδιωτική βάση δεδομένων: συνδέετε το δικό σας έργο Supabase. Εσείς είστε ο υπεύθυνος επεξεργασίας· εμείς δεν βλέπουμε ποτέ αυτά τα δεδομένα.
  • Συμμετοχή σε ομάδα: συνδέετε ένα έργο Supabase που λειτουργεί κάποιος που γνωρίζετε (οικογένεια, φίλοι). Το πρόσωπο αυτό είναι ο υπεύθυνος επεξεργασίας της κοινόχρηστης βάσης δεδομένων.
  • Sparkilo Community: συνδέετε την κοινόχρηστη βάση δεδομένων που λειτουργεί ο προαναφερόμενος προγραμματιστής (Supabase, φιλοξενούμενη στην ΕΕ — AWS eu-central-1, Φρανκφούρτη). Ο προγραμματιστής είναι ο υπεύθυνος επεξεργασίας· η Supabase, Inc. είναι εκτελών την επεξεργασία, δεσμευόμενος από τους όρους επεξεργασίας δεδομένων της.

Η εφαρμογή σάς ενημερώνει ποια από αυτές τις περιπτώσεις ισχύει πριν συνδεθείτε, και το εμφανίζει ξανά στις Ρυθμίσεις → Πίνακας απορρήτου.

4. Δεδομένα που ΔΕΝ συλλέγουμε

  • Όνομα ή αριθμός τηλεφώνου (διεύθυνση e-mail αποθηκεύεται μόνο εάν τη συνδέσετε με τον προαιρετικό λογαριασμό TankSync σας)
  • Στοιχεία πληρωμής ή τραπεζικά στοιχεία
  • Δεδομένα υγείας ή φυσικής κατάστασης
  • Επαφές, μηνύματα ή αρχεία κλήσεων
  • Φωτογραφίες, βίντεο ή αρχεία πέραν της φωτογραφίας απόδειξης που επιλέγετε να σαρώσετε
  • Ιστορικό περιήγησης
  • Διαφημιστικά αναγνωριστικά

Τα λογότυπα των εταιρειών περιλαμβάνονται στην εφαρμογή. Η φόρτωσή τους από το διαδίκτυο (logo.clearbit.com, που θα λάμβανε τη διεύθυνση IP σας) είναι απενεργοποιημένη, εκτός εάν την ενεργοποιήσετε στις Ρυθμίσεις → Απόρρητο.

5. Υπηρεσίες τρίτων και πηγές δεδομένων

Η εφαρμογή επικοινωνεί με τις ακόλουθες υπηρεσίες. Καθεμία έχει τη δική της πολιτική απορρήτου. Η εφαρμογή δεν κοινοποιεί ποτέ δεδομένα μεταξύ τους και δεν αποστέλλει ποτέ περισσότερα από όσα περιγράφουν οι παραπάνω στήλες.

5.1 Υποδομή (μόνο όταν η αντίστοιχη λειτουργία είναι ενεργοποιημένη)

  • Supabase (klelxnkzrxlpzuddhpfg.supabase.co, AWS eu-central-1) — backend του TankSync για το Sparkilo Community και για τον διακομιστή μεσολάβησης πλακιδίων. Εκτελών την επεξεργασία βάσει της πρόσθετης πράξης επεξεργασίας δεδομένων της Supabase.
  • Sentry (sentry.io) — αναφορές σφαλμάτων και ίχνη επιδόσεων, μόνο κατόπιν ρητής ενεργοποίησης. Η Sentry ενδέχεται να επεξεργάζεται δεδομένα στις Ηνωμένες Πολιτείες· οι διαβιβάσεις καλύπτονται από το Πλαίσιο Προστασίας Δεδομένων ΕΕ-ΗΠΑ και από τυποποιημένες συμβατικές ρήτρες.
  • GitHub (api.github.com, github.com) — αναφορές ζητημάτων που υποβάλλετε ρητά· η εφαρμογή κατεβάζει επίσης δημόσια πακέτα δεδομένων (έξοδοι αυτοκινητοδρόμων, λίστες σταθμών) από τις εκδόσεις (releases) του έργου, γεγονός που αποκαλύπτει τη διεύθυνση IP σας στο GitHub.
  • OpenStreetMap (tile.openstreetmap.org, nominatim.openstreetmap.org), OSRM (router.project-osrm.org), Overpass API (overpass-api.de) — χάρτες, γεωκωδικοποίηση, δρομολόγηση.
  • OpenChargeMap (api.openchargemap.io) και ODRÉ / IRVE (odre.opendatasoft.com) — σταθμοί και τιμές φόρτισης ηλεκτρικών οχημάτων. Λαμβάνουν: συντεταγμένες αναζήτησης.
  • NHTSA vPIC (vpic.nhtsa.dot.gov) — αποκωδικοποίηση VIN, υπό την προϋπόθεση συγκατάθεσης.
  • Clearbit Logo API (logo.clearbit.com) — λογότυπα εταιρειών, απενεργοποιημένο από προεπιλογή.
  • Apple Maps / Google Maps (www.google.com) — ανοίγουν στο πρόγραμμα περιήγησης ή στην εφαρμογή χαρτών σας μόνο όταν πατήσετε «Πλοήγηση».

6. Ασφάλεια δεδομένων

  • Όλη η επικοινωνία δικτύου χρησιμοποιεί HTTPS (TLS κατά τη μεταφορά)· η εφαρμογή απορρίπτει τελικά σημεία συγχρονισμού απλού HTTP.
  • Τα κλειδιά API, το token GitHub σας και η συνεδρία TankSync φυλάσσονται σε εγγενή κρυπτογραφημένη αποθήκευση της πλατφόρμας (Android Keystore / iOS Keychain).
  • Οι τοπικές βάσεις δεδομένων είναι κρυπτογραφημένες με AES, με κλειδί που φυλάσσεται στο Keystore / Keychain — συμπεριλαμβανομένων των καταγεγραμμένων διαδρομών, των δεδομένων οχημάτων, των υπενθυμίσεων συντήρησης και των προσωρινά αποθηκευμένων τιμών.
  • Στον διακομιστή, κάθε πίνακας προστατεύεται με ασφάλεια σε επίπεδο γραμμής, ώστε ένας λογαριασμός να μπορεί να διαβάζει ή να διαγράφει μόνο τις δικές του γραμμές· οι κοινόχρηστες αξιολογήσεις και οι κοινοτικές αναφορές τιμών είναι οι μόνες γραμμές ορατές σε άλλους συνδεδεμένους χρήστες.
  • Τα ίχνη σφαλμάτων καθαρίζονται από διευθύνσεις e-mail, συντεταγμένες και token πριν αποθηκευτούν ή αποσταλούν.
  • Κανένα δεδομένο δεν αποστέλλεται σε κανέναν διακομιστή, εκτός εάν εκτελέσετε αναζήτηση, ανοίξετε χάρτη ή ενεργοποιήσετε το TankSync / τα διαγνωστικά.

7. Τα δικαιώματά σας

Σύμφωνα με τα άρθρα 15–22 ΓΚΠΔ έχετε δικαίωμα πρόσβασης, διόρθωσης, διαγραφής, περιορισμού και φορητότητας των δεδομένων σας, δικαίωμα εναντίωσης στην επεξεργασία που βασίζεται σε έννομο συμφέρον, και δικαίωμα ανάκλησης της συγκατάθεσής σας ανά πάσα στιγμή, χωρίς να θίγεται η νομιμότητα της προηγούμενης επεξεργασίας. Κάθε δικαίωμα έχει ένα κουμπί στην εφαρμογή:

  • Πρόσβαση — Ρυθμίσεις → Πίνακας απορρήτου εμφανίζει κάθε κατηγορία που είναι αποθηκευμένη στη συσκευή και, όταν είστε συνδεδεμένοι, κάθε γραμμή της βάσης δεδομένων TankSync σας.
  • Εξαγωγή (φορητότητα) — Πίνακας απορρήτου → Εξαγωγή όλων των δεδομένων μου δημιουργεί ένα αρχείο ZIP με ένα μηχαναγνώσιμο JSON ανά κατηγορία (αγαπημένα, ειδοποιήσεις, προφίλ, δρομολόγια, ιστορικό τιμών, οχήματα, ανεφοδιασμοί, διαδρομές με δείγματα GPS και ένα GPX ανά διαδρομή, τιμές αναφοράς, υπενθυμίσεις συντήρησης, ημερολόγια φόρτισης, το αρχείο συγκαταθέσεών σας) καθώς και εξαγωγή JSON κάθε πίνακα του διακομιστή.
  • Διόρθωση — επεξεργαστείτε οποιαδήποτε καταχώριση απευθείας στην εφαρμογή· η αλλαγή συγχρονίζεται εάν το TankSync είναι ενεργοποιημένο.
  • Διαγραφή — βλ. Ενότητα 8.
  • Περιορισμός / εναντίωση — απενεργοποιήστε το TankSync, τον συγχρονισμό διαδρομών, τον διακομιστή μεσολάβησης πλακιδίων ή τα διαγνωστικά στις Ρυθμίσεις· ανακαλέστε την άδεια τοποθεσίας, Bluetooth, κάμερας ή ειδοποιήσεων στις ρυθμίσεις της συσκευής σας.
  • Ανάκληση συγκατάθεσης — Ρυθμίσεις → Απόρρητο και δεδομένα απαριθμεί κάθε συγκατάθεση με την ημερομηνία που τη δώσατε και την έκδοση της πολιτικής που είδατε· καθεμία μπορεί να απενεργοποιηθεί, και η εφαρμογή σταματά αμέσως την αντίστοιχη επεξεργασία.
  • Καταγγελία — μπορείτε να υποβάλετε καταγγελία σε εποπτική αρχή, ιδίως στο κράτος μέλος της ΕΕ της συνήθους διαμονής σας, του τόπου εργασίας σας ή του τόπου της εικαζόμενης παράβασης. Θα εκτιμούσαμε την ευκαιρία να απαντήσουμε πρώτα εμείς στο ζήτημά σας: fdittgen@gmail.com.

8. Διαγραφή του λογαριασμού και των δεδομένων σας

Μπορείτε να διαγράψετε τα πάντα μόνοι σας, απευθείας από την εφαρμογή — χωρίς να χρειάζεται αίτημα υποστήριξης:

  • Τοπικά δεδομένα: Ρυθμίσεις → Πίνακας απορρήτου → Διαγραφή όλων των δεδομένων αφαιρεί κάθε βάση δεδομένων που τηρεί η εφαρμογή στη συσκευή — προφίλ, αγαπημένα, ειδοποιήσεις, ιστορικό τιμών, προσωρινά αποθηκευμένες τιμές, οχήματα, ανεφοδιασμούς, καταγεγραμμένες διαδρομές και τα δείγματα GPS τους, τιμές αναφοράς OBD2 και προσωρινές μνήμες προσαρμογέων, υπενθυμίσεις συντήρησης, επιτεύγματα, ίχνη σφαλμάτων, κλειδιά API, token και τα δεδομένα του widget της αρχικής οθόνης — και επαναφέρει την εφαρμογή στην κατάσταση πρώτης εκκίνησης.
  • Λογαριασμός TankSync και δεδομένα διακομιστή: TankSync → Διαφάνεια δεδομένων → Διαγραφή λογαριασμού διαγράφει σε μία συναλλαγή κάθε γραμμή που σας ανήκει (αγαπημένα, ειδοποιήσεις, αγνοημένους σταθμούς, αναφορές τιμών, αναφορές περιεχομένου, οχήματα, ανεφοδιασμούς, δρομολόγια, τιμές αναφοράς, αξιολογήσεις, διαδρομές, κοινοποιήσεις διαδρομών που δώσατε ή λάβατε, σήματα χρόνου αναμονής, ρυθμίσεις συγχρονισμού, εγγραφές διαγραφής και τη γραμμή χρήστη σας) και στη συνέχεια διαγράφει την ίδια την ταυτότητα του λογαριασμού, συμπεριλαμβανομένης οποιασδήποτε συνδεδεμένης διεύθυνσης e-mail. Εάν κάποιος πίνακας δεν μπόρεσε να διαγραφεί, η εφαρμογή σάς ενημερώνει ποιος, αντί να δηλώσει επιτυχία. Η ενέργεια αυτή δεν μπορεί να αναιρεθεί.
  • Μεμονωμένα στοιχεία: κάθε αγαπημένο, ειδοποίηση, όχημα, ανεφοδιασμός, διαδρομή, αναφορά τιμής και αναφορά περιεχομένου μπορεί να διαγραφεί ξεχωριστά· οι διαγραφές μεταδίδονται στις άλλες συσκευές σας.

Εάν δεν μπορείτε πλέον να αποκτήσετε πρόσβαση στην εφαρμογή, μπορείτε να ζητήσετε διαγραφή επικοινωνώντας με τον προγραμματιστή (Ενότητα 11)· παρακαλούμε γράψτε από τη διεύθυνση e-mail που είναι συνδεδεμένη με τον λογαριασμό σας, ώστε να μπορέσουμε να επαληθεύσουμε ότι σας ανήκει. Ένας ανώνυμος λογαριασμός που δεν συνδέθηκε ποτέ με e-mail δεν μπορεί να ταυτοποιηθεί από κανέναν — ούτε από εμάς — χωρίς τη συσκευή στην οποία δημιουργήθηκε.
