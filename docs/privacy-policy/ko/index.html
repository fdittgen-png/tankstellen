1. 개요

Sparkilo는 주행 기록 기능(선택 사항)을 갖춘 무료 오픈소스 연료 및 전기차 충전 가격 비교 앱입니다. 이 앱은 로컬 우선(local-first) 원칙으로 설계되었습니다. 즉, 앱이 귀하에 관해 알고 있는 모든 정보는 귀하가 별도로 명시된 기능을 켜지 않는 한 귀하의 휴대전화에만 저장됩니다. 광고, 추적 픽셀, 광고 식별자, 분석 SDK는 일절 없습니다. 본 방침은 EU 일반개인정보보호법(GDPR)을 준수하도록 작성되었으며, 귀하가 어디에 계시든 모든 이용자에게 적용됩니다.

이 앱은 오픈소스입니다. 아래의 모든 내용은 코드에서 직접 확인하실 수 있습니다. 처리되는 정보에 대한 기계 판독 가능한 요약은 docs/privacy/data_inventory.json에 유지되며, 본 페이지, 스토어 신고 내용, 코드가 서로 어긋나면 앱 자체의 테스트가 실패하도록 되어 있습니다.

  • TankSync 미사용(기본값): 당사가 운영하는 어떤 서버에도 아무것도 저장되지 않습니다. 귀하의 데이터는 귀하의 기기에 남아 있으며, 귀하만이 이를 통제합니다.
  • 개인 데이터베이스: 귀하가 직접 소유한 Supabase 프로젝트에 연결합니다. 귀하가 개인정보처리자이며, 당사는 해당 데이터를 전혀 볼 수 없습니다.
  • 그룹 참여: 귀하가 아는 사람(가족, 친구)이 운영하는 Supabase 프로젝트에 연결합니다. 그 사람이 공유 데이터베이스의 개인정보처리자입니다.
  • Sparkilo Community: 위에 명시된 개발자가 운영하는 공유 데이터베이스에 연결합니다(Supabase, EU 내 호스팅 — AWS eu-central-1, 프랑크푸르트). 개발자가 개인정보처리자이며, Supabase, Inc.는 자사의 데이터 처리 약관에 구속되는 수탁자(처리자)입니다.

앱은 연결하기 전에 이 중 어느 경우에 해당하는지 알려 드리며, 설정 → 개인정보 대시보드에서 다시 표시합니다.

4. 당사가 수집하지 않는 데이터

  • 이름 또는 전화번호(이메일 주소는 귀하가 선택 사항인 TankSync 계정에 연결한 경우에만 저장됨)
  • 결제 또는 은행 정보
  • 건강 또는 운동 데이터
  • 연락처, 메시지 또는 통화 기록
  • 귀하가 스캔하기로 선택한 영수증 사진 이외의 사진, 동영상 또는 파일
  • 검색 기록(브라우징 기록)
  • 광고 식별자

브랜드 로고는 앱에 내장되어 있습니다. 인터넷에서 로고를 불러오는 기능(logo.clearbit.com, 이 경우 귀하의 IP 주소가 전송됨)은 귀하가 설정 → 개인정보에서 켜지 않는 한 꺼져 있습니다.

5. 제3자 서비스 및 데이터 출처

앱은 다음 서비스와 통신합니다. 각 서비스는 자체 개인정보 처리방침을 갖고 있습니다. 앱은 이들 서비스 간에 데이터를 공유하지 않으며, 위 표의 각 열에 기재된 것 이상을 전송하지 않습니다.

5.1 인프라(해당 기능이 켜진 경우에만)

  • Supabase (klelxnkzrxlpzuddhpfg.supabase.co, AWS eu-central-1) — Sparkilo Community용 TankSync 백엔드 및 타일 프록시. Supabase의 데이터 처리 부속 계약에 따른 수탁자(처리자).
  • Sentry (sentry.io) — 충돌 보고서 및 성능 추적, 동의 시에만. Sentry는 미국에서 데이터를 처리할 수 있으며, 이전은 EU-US Data Privacy Framework 및 표준계약조항에 의해 보호됩니다.
  • GitHub (api.github.com, github.com) — 귀하가 명시적으로 제출한 이슈 신고; 앱은 또한 프로젝트 릴리스에서 공개 데이터 자산(고속도로 출구, 주유소 목록)을 다운로드하며, 이 과정에서 귀하의 IP 주소가 GitHub에 노출됩니다.
  • OpenStreetMap (tile.openstreetmap.org, nominatim.openstreetmap.org), OSRM (router.project-osrm.org), Overpass API (overpass-api.de) — 지도, 지오코딩, 경로 안내.
  • OpenChargeMap (api.openchargemap.io) 및 ODRÉ / IRVE (odre.opendatasoft.com) — 전기차 충전소 및 가격. 수신 데이터: 검색 좌표.
  • NHTSA vPIC (vpic.nhtsa.dot.gov) — VIN 해독, 동의 필요.
  • Clearbit Logo API (logo.clearbit.com) — 브랜드 로고, 기본적으로 꺼짐.
  • Apple Maps / Google Maps (www.google.com) — "길찾기"를 누를 때에만 브라우저 또는 지도 앱에서 열림.

6. 데이터 보안

  • 모든 네트워크 통신은 HTTPS(전송 중 TLS)를 사용하며, 앱은 암호화되지 않은 HTTP 동기화 엔드포인트를 거부합니다.
  • API 키, 귀하의 GitHub 토큰 및 TankSync 세션은 플랫폼 고유의 암호화 저장소(Android Keystore / iOS Keychain)에 보관됩니다.
  • 로컬 데이터베이스는 Keystore / Keychain에 보관된 키로 AES 암호화됩니다 — 기록된 주행, 차량 데이터, 정비 알림 및 캐시된 가격을 포함합니다.
  • 서버에서는 모든 테이블이 행 수준 보안으로 보호되어 계정은 자신의 행만 읽거나 삭제할 수 있습니다. 공유 평가와 커뮤니티 가격 제보만이 로그인한 다른 이용자에게 표시되는 유일한 행입니다.
  • 오류 추적은 저장 또는 전송 전에 이메일 주소, 좌표 및 토큰이 제거됩니다.
  • 귀하가 검색을 실행하거나, 지도를 열거나, TankSync / 진단을 켜지 않는 한 어떤 서버로도 데이터가 전송되지 않습니다.

7. 귀하의 권리

GDPR 제15조~제22조에 따라 귀하는 데이터에 대한 열람, 정정, 삭제, 처리 제한 및 이동을 요구할 권리, 정당한 이익에 근거한 처리에 반대할 권리, 그리고 이전 처리의 적법성에 영향을 미치지 않으면서 언제든지 동의를 철회할 권리를 갖습니다. 각 권리는 앱 내 버튼으로 행사할 수 있습니다.

  • 열람 — 설정 → 개인정보 대시보드에서 기기에 저장된 모든 범주와, 연결된 경우 귀하의 TankSync 데이터베이스의 모든 행을 확인할 수 있습니다.
  • 내보내기(이동권) — 개인정보 대시보드 → 내 모든 데이터 내보내기는 범주별 기계 판독 가능 JSON(즐겨찾기, 알림, 프로필, 여정, 가격 이력, 차량, 주유 기록, GPS 샘플이 포함된 주행 및 주행별 GPX 파일, 기준값, 정비 알림, 충전 기록, 귀하의 동의 기록)과 모든 서버 테이블의 JSON 내보내기를 담은 ZIP 파일 하나를 생성합니다.
  • 정정 — 앱에서 직접 모든 항목을 편집할 수 있으며, TankSync가 켜져 있으면 변경 사항이 동기화됩니다.
  • 삭제 — 제8절을 참조하십시오.
  • 처리 제한 / 반대 — 설정에서 TankSync, 주행 동기화, 타일 프록시 또는 진단을 끄고, 기기 설정에서 위치, Bluetooth, 카메라 또는 알림 권한을 철회할 수 있습니다.
  • 동의 철회 — 설정 → 개인정보 및 데이터에는 귀하가 동의한 날짜와 당시 확인한 방침 버전과 함께 모든 동의 항목이 나열됩니다. 각 항목을 끌 수 있으며, 앱은 해당 처리를 즉시 중단합니다.
  • 불만 제기 — 귀하는 감독기관, 특히 귀하의 상거소, 근무지 또는 침해 혐의가 발생한 장소가 있는 EU 회원국의 감독기관에 불만을 제기할 수 있습니다. 먼저 귀하의 우려 사항을 해결할 기회를 주시면 감사하겠습니다: fdittgen@gmail.com.

8. 계정 및 데이터 삭제

고객 지원 요청 없이 앱에서 직접 모든 것을 삭제하실 수 있습니다.

  • 로컬 데이터: 설정 → 개인정보 대시보드 → 모든 데이터 삭제는 앱이 기기에 보관하는 모든 데이터베이스 — 프로필, 즐겨찾기, 알림, 가격 이력, 캐시된 가격, 차량, 주유 기록, 기록된 주행 및 GPS 샘플, OBD2 기준값 및 어댑터 캐시, 정비 알림, 업적, 오류 추적, API 키, 토큰 및 홈 화면 위젯 데이터 — 를 제거하고 앱을 최초 실행 상태로 되돌립니다.
  • TankSync 계정 및 서버 데이터: TankSync → 데이터 투명성 → 계정 삭제는 귀하가 소유한 모든 행(즐겨찾기, 알림, 무시한 주유소, 가격 제보, 콘텐츠 신고, 차량, 주유 기록, 여정, 기준값, 평가, 주행, 귀하가 주고받은 주행 공유, 대기 시간 핑, 동기화 설정, 삭제 기록 및 귀하의 사용자 행)을 하나의 트랜잭션으로 지운 다음, 연결된 이메일 주소를 포함하여 계정 신원 자체를 삭제합니다. 어떤 테이블이라도 지울 수 없었던 경우, 앱은 성공했다고 주장하는 대신 어느 테이블인지 알려 드립니다. 이 작업은 되돌릴 수 없습니다.
  • 개별 항목: 모든 즐겨찾기, 알림, 차량, 주유 기록, 주행, 가격 제보 및 콘텐츠 신고는 개별적으로 삭제할 수 있으며, 삭제는 귀하의 다른 기기에도 전파됩니다.

더 이상 앱에 접근할 수 없는 경우, 개발자에게 연락하여(제11절) 삭제를 요청하실 수 있습니다. 소유권을 확인할 수 있도록 계정에 연결된 이메일 주소로 보내 주시기 바랍니다. 이메일에 연결된 적이 없는 익명 계정은 계정이 생성된 기기 없이는 당사를 포함한 누구도 식별할 수 없습니다.
