1. Pārskats

Sparkilo ir bezmaksas atvērtā pirmkoda lietotne degvielas un elektroauto uzlādes cenu salīdzināšanai ar izvēles braucienu ierakstīšanas funkciju. Tā ir veidota pēc „local-first” principa: viss, ko lietotne zina par Jums, atrodas Jūsu tālrunī, ja vien Jūs neieslēdzat funkciju, kurā skaidri norādīts citādi. Nav reklāmu, izsekošanas pikseļu, reklāmas identifikatoru un analītikas SDK. Šī politika ir izstrādāta tā, lai atbilstu ES Vispārīgajai datu aizsardzības regulai (VDAR / GDPR); tā attiecas uz ikvienu lietotāju neatkarīgi no tā, kur Jūs atrodaties.

Lietotne ir atvērtā pirmkoda — katru turpmāk minēto apgalvojumu var pārbaudīt kodā. Mašīnlasāms apstrādāto datu kopsavilkums glabājas failā docs/privacy/data_inventory.json, un lietotnes pašas testi neizdodas, ja šī lapa, veikalu deklarācijas un kods vairs nesakrīt.

5. Trešo pušu pakalpojumi un datu avoti

Lietotne sazinās ar šādiem pakalpojumiem. Katram no tiem ir sava privātuma politika. Lietotne nekad nekopīgo datus starp tiem un nekad nenosūta vairāk, nekā aprakstīts iepriekš minētajās kolonnās.

5.1 Infrastruktūra (tikai tad, kad ieslēgta attiecīgā funkcija)

  • Supabase (klelxnkzrxlpzuddhpfg.supabase.co, AWS eu-central-1) — „Sparkilo Community” TankSync aizmugursistēma un flīžu starpniekserveris. Apstrādātājs saskaņā ar Supabase datu apstrādes pielikumu.
  • Sentry (sentry.io) — avāriju ziņojumi un veiktspējas pēdas, tikai ar piekrišanu. Sentry var apstrādāt datus Amerikas Savienotajās Valstīs; nosūtīšanu sedz ES un ASV datu privātuma regulējums (EU-US Data Privacy Framework) un līguma standartklauzulas.
  • GitHub (api.github.com, github.com) — problēmu ziņojumi, ko Jūs skaidri iesniedzat; lietotne no projekta laidieniem lejupielādē arī publiskus datu resursus (automaģistrāļu nobrauktuves, staciju sarakstus), kas atklāj GitHub Jūsu IP adresi.
  • OpenStreetMap (tile.openstreetmap.org, nominatim.openstreetmap.org), OSRM (router.project-osrm.org), Overpass API (overpass-api.de) — kartes, ģeokodēšana, maršrutēšana.
  • OpenChargeMap (api.openchargemap.io) un ODRÉ / IRVE (odre.opendatasoft.com) — elektroauto uzlādes stacijas un cenas. Saņem: meklēšanas koordinātas.
  • NHTSA vPIC (vpic.nhtsa.dot.gov) — VIN atšifrēšana, tikai ar piekrišanu.
  • Clearbit Logo API (logo.clearbit.com) — zīmolu logotipi, pēc noklusējuma izslēgts.
  • Apple Maps / Google Maps (www.google.com) — tiek atvērts Jūsu pārlūkprogrammā vai karšu lietotnē tikai tad, kad Jūs pieskaraties „Navigēt”.

6. Datu drošība

  • Visa tīkla saziņa notiek, izmantojot HTTPS (TLS pārsūtīšanas laikā); lietotne atsakās izmantot nešifrētus HTTP sinhronizācijas galapunktus.
  • API atslēgas, Jūsu GitHub pilnvara un TankSync sesija glabājas platformas iebūvētajā šifrētajā krātuvē (Android Keystore / iOS Keychain).
  • Lokālās datubāzes ir šifrētas ar AES, izmantojot atslēgu, kas glabājas Keystore / Keychain — tostarp ierakstītie braucieni, transportlīdzekļu dati, apkopes atgādinājumi un kešatmiņā saglabātās cenas.
  • Serverī katru tabulu aizsargā rindu līmeņa drošība, tāpēc konts var lasīt vai dzēst tikai savas rindas; kopīgotie vērtējumi un kopienas cenu ziņojumi ir vienīgās rindas, kas redzamas citiem pierakstījušamies lietotājiem.
  • No kļūdu pēdām pirms glabāšanas vai nosūtīšanas tiek izņemtas e-pasta adreses, koordinātas un pilnvaras.
  • Nekādi dati netiek nosūtīti nevienam serverim, ja vien Jūs neveicat meklēšanu, neatverat karti vai neieslēdzat TankSync / diagnostiku.

7. Jūsu tiesības

Saskaņā ar VDAR 15.–22. pantu Jums ir tiesības piekļūt saviem datiem, tos labot, dzēst, ierobežot to apstrādi un tos pārnest, iebilst pret apstrādi, kas balstīta uz leģitīmām interesēm, un jebkurā laikā atsaukt piekrišanu, neietekmējot iepriekšējās apstrādes likumību. Katrai tiesībai lietotnē ir poga:

  • Piekļuve — Iestatījumi → Privātuma panelis parāda katru ierīcē glabāto kategoriju un, ja esat pievienojies, katru rindu Jūsu TankSync datubāzē.
  • Eksports (pārnesamība) — Privātuma panelis → Eksportēt visus manus datus izveido vienu ZIP failu ar mašīnlasāmu JSON failu katrai kategorijai (izlase, brīdinājumi, profili, maršruti, cenu vēsture, transportlīdzekļi, uzpildes, braucieni ar GPS paraugiem un viens GPX fails katram braucienam, bāzes vērtības, apkopes atgādinājumi, uzlādes žurnāli, Jūsu piekrišanu reģistrs), kā arī katras servera tabulas JSON eksportu.
  • Labošana — rediģējiet jebkuru ierakstu tieši lietotnē; ja TankSync ir ieslēgts, izmaiņas tiek sinhronizētas.
  • Dzēšana — skatīt 8. sadaļu.
  • Ierobežošana / iebildumi — iestatījumos izslēdziet TankSync, braucienu sinhronizāciju, flīžu starpniekserveri vai diagnostiku; ierīces iestatījumos atsauciet atrašanās vietas, Bluetooth, kameras vai paziņojumu atļauju.
  • Piekrišanas atsaukšana — Iestatījumi → Privātums un dati uzskaita katru piekrišanu ar tās sniegšanas datumu un Jūsu redzēto politikas versiju; katru var izslēgt, un lietotne nekavējoties pārtrauc attiecīgo apstrādi.
  • Sūdzība — Jūs varat iesniegt sūdzību uzraudzības iestādei, jo īpaši tajā ES dalībvalstī, kurā ir Jūsu pastāvīgā dzīvesvieta, darba vieta vai iespējamā pārkāpuma izdarīšanas vieta. Mēs būtu pateicīgi par iespēju vispirms pašiem atrisināt Jūsu jautājumu: fdittgen@gmail.com.

8. Konta un datu dzēšana

Visu varat izdzēst paši, tieši lietotnē — atbalsta pieprasījums nav nepieciešams:

  • Lokālie dati: Iestatījumi → Privātuma panelis → Dzēst visus datus noņem katru datubāzi, ko lietotne glabā ierīcē — profilus, izlasi, brīdinājumus, cenu vēsturi, kešatmiņā saglabātās cenas, transportlīdzekļus, uzpildes, ierakstītos braucienus un to GPS paraugus, OBD2 bāzes vērtības un adapteru kešatmiņas, apkopes atgādinājumus, sasniegumus, kļūdu pēdas, API atslēgas, pilnvaras un sākuma ekrāna logrīka datus — un atgriež lietotni pirmās palaišanas stāvoklī.
  • TankSync konts un servera dati: TankSync → Datu caurskatāmība → Dzēst kontu vienā transakcijā dzēš katru Jums piederošo rindu (izlasi, brīdinājumus, ignorētās stacijas, cenu ziņojumus, ziņojumus par saturu, transportlīdzekļus, uzpildes, maršrutus, bāzes vērtības, vērtējumus, braucienus, Jūsu sniegtos vai saņemtos braucienu kopīgojumus, gaidīšanas laika signālus, sinhronizācijas iestatījumus, dzēšanas ierakstus un Jūsu lietotāja rindu) un pēc tam dzēš pašu konta identitāti, tostarp jebkuru piesaistīto e-pasta adresi. Ja kādu tabulu neizdevās dzēst, lietotne paziņo, kuru, nevis apgalvo, ka viss izdevies. Šo darbību nevar atsaukt.
  • Atsevišķi vienumi: katru izlases ierakstu, brīdinājumu, transportlīdzekli, uzpildi, braucienu, cenu ziņojumu un ziņojumu par saturu var dzēst atsevišķi; dzēšana tiek pārnesta uz citām Jūsu ierīcēm.

Ja Jūs vairs nevarat piekļūt lietotnei, dzēšanu varat pieprasīt, sazinoties ar izstrādātāju (11. sadaļa); lūdzu, rakstiet no kontam piesaistītās e-pasta adreses, lai mēs varētu pārbaudīt piederību. Anonīmu kontu, kas nekad nav bijis piesaistīts e-pastam, neviens — arī mēs — nevar identificēt bez ierīces, kurā tas tika izveidots.
