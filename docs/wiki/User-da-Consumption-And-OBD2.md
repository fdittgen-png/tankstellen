# Brændstof, ture og kørsel *(flyttet)*

Denne side er delt i tre, så hvert emne har sine egne ankre med henblik på en fremtidig hjælp i appen:

- **[Køretøjer og OBD2](User-da-Vehicles-And-OBD2)** — din bil, tankkapacitet, flex-fuel, adapterparring, basisliniekalibrering, automatisk optagelse.
- **[Tankbog og forbrug](User-da-Fuel-And-Consumption)** — tankninger, tankniveau, tankrapport, præcision, pris pr. kilometer pr. brændstof.
- **[Ture og øko-coaching](User-da-Trips-And-Coaching)** — optagelse, turdetaljen, kørescore, CO₂-oversigt.

Start med **[Sådan fungerer Sparkilo](User-da-How-It-Works)**, hvis du vil have begreberne bag alle tre.
